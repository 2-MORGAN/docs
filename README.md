# Documentation Nimbus

Documentation utilisateur de Nimbus, publiée sur <https://2morgan.mintlify.app> depuis la branche `main`.

- Pages en MDX, navigation et redirections dans [docs.json](docs.json).
- Règles de rédaction et de mise à jour : [AGENTS.md](AGENTS.md).
- Point d'entrée des agents : [llms.txt](llms.txt) et `agents/`.

Aperçu local : `npx mint dev` à la racine, puis <http://localhost:3000>.
